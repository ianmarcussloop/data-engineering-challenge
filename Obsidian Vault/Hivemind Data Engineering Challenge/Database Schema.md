*"chargers" Table*
Primary Keys = charger name + timestamp
Indicies = action (needed?)

| Column              | Description                                                                                                                                                                                                                                                                                                     | Type                       |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| sessionId           | charger name + timestamp                                                                                                                                                                                                                                                                                        | str, primary key, not null |
| stationId           | charger name                                                                                                                                                                                                                                                                                                    | str, not null              |
| status              | - if at least one `MeterValues` exists -> "active"<br>- if at least one `MeterValues` and a `StopTransaction` -> "ended"<br>- if no MeterValues exist -> null                                                                                                                                                   | str                        |
| terminationReason   | - if status = active -> null<br>- if status = ended -> `reason` field from `StopTransaction`<br>if status = null -> null                                                                                                                                                                                        | str                        |
| startTime           | - smallest timestamp of all `MeterValues`<br>(can we assume the data is ordered chronologically so we can just take the first `MeterValue`?)                                                                                                                                                                    | timestamp                  |
| lastSeen            | - latest timestamp (lastSeen should be endTime if status = "ended". Otherwise endTime is null, and lastSeen is the latest timestamp if status = "active")                                                                                                                                                       | timestamp                  |
| endTime             | - timestamp of `StopTransaction` action<br>- null if no `StopTransaction` exists                                                                                                                                                                                                                                | timestamp                  |
| duration            | - if endTime not null -> endTime - startTime<br>- otherwise timestamp of the latest `MeterValue` (or `Heartbeat`?) - startTime (in seconds (?))<br>(or should duration be null when endTime is null (?))<br>(do we want to define this at all yet if the status is still active and the session isnt ended (?)) | int                        |
| totalEnergyConsumed | Average `Power.Active.Import` * duration (in kWh)                                                                                                                                                                                                                                                               | double                     |
| eventCount          | total number of actions for this stationId                                                                                                                                                                                                                                                                      | int                        |
